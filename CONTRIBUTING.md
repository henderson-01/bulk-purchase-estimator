# Contributing to the bulk-purchase-estimator

Thank you for your interest in this project!

This repository is part of my personal learning journey. The code is intended for educational purposes and serves as a practical exercise to reinforce my understanding of Python concepts.

## Contribution Policy

While I truly appreciate any interest in this project, **I will not be accepting pull requests to merge into the main branch.** This is a learning project where I want to maintain full control over the code development process to ensure I'm properly learning and implementing concepts as I go.

## What You Can Do

- **Fork the Repository**: Feel free to fork this repository and experiment with the code on your own.
- **Make Changes Locally**: Modify the code, test it, and learn from it in your own environment.
- **Share Feedback**: If you have suggestions or find bugs (that aren't related to learning objectives), feel free to open an issue.

## Acknowledgments

Thank you for understanding, and happy coding!
